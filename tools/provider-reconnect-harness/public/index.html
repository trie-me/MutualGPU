Run full certification is the one-press suite: it provisions an isolated browser provider, runs deterministic SDK checks plus the successful, terminal-failure, and requestor-cancellation scenarios, then reports every expected outcome. SDK checks include reconnect-time progress, completion-acknowledgement replay, and recovery-expiry handling. It may create a fresh isolated provider after a failed scenario so subsequent checks remain independent. The full pipeline creates one requestor task, forces one reconnect, proves duplicate progress is non-fatal, sends wrong-handle and malformed-progress frames that must be rejected and recover, then verifies browser retrieval of every result artifact. Credentials, task handles, upload tokens, and signed URLs stay in page memory only.
